# 🐾 TamaBot — развлекательный Telegram-бот (тамагочи + достижения + топы)

[![Python](https://img.shields.io/badge/Python-3.11%2B-blue.svg)](https://www.python.org/)
[![aiogram](https://img.shields.io/badge/aiogram-3.x-green.svg)](https://docs.aiogram.dev/)
[![MySQL](https://img.shields.io/badge/MySQL-8+-4479A1.svg)](https://www.mysql.com/)
[![Textual](https://img.shields.io/badge/TamaConsole-Textual%208-orange.svg)](https://textual.textualize.io/)

Многофункциональный развлекательный бот с виртуальным питомцем (тамагочи), системой
достижений, топами активности и мини-играми. Работает в связке **«канал + привязанная
группа обсуждения»**: считает сообщения, реакции и стрики участников, а весь интерактив
выносит в личные сообщения. Управление — через интерактивные кнопки с единой
пагинированной навигацией. Запуск и обслуживание — на **Windows Server** через BAT-скрипты
и встроенную консоль управления **TamaConsole**.

> 📂 Основной код проекта — в папке [`bot/`](bot/).
> Полная документация по установке, настройке и эксплуатации: **[bot/README.md](bot/README.md)**.
> Этот файл — быстрый старт и обзор возможностей.

## 🔒 Модель доступа

* **Только личные сообщения.** Всё взаимодействие с ботом (меню, кнопки, команды,
  уведомления) происходит исключительно в ЛС. В группах и каналах бот **молчит**:
  ничего туда не пишет, не отвечает на команды и не трогает чужие сообщения —
  активность участников считается без какого-либо визуального шума.
* **Доступ по подписке (v1.5.6).** Бот отвечает только подписчикам хотя бы
  ОДНОГО из чатов `TRACKED_CHAT_IDS` (если список пуст — каналу
  `CHANNEL_USERNAME` / `CHANNEL_CHAT_ID`). Если пользователь отписался,
  вместо ответа показывается мягкая заглушка «🔒 Бот доступен только
  подписчикам канала» с кнопками «📢 Подписаться» и «✅ Я подписался —
  проверить». Проверка выполняется через `getChatMember` по каждому
  обязательному чату: положительный результат кэшируется ~на 5 минут,
  отрицательный — на 15 секунд; при недоступности Telegram API действует
  правило fail-open (пользователя не блокируем из-за сбоя). Если ни один
  чат не настроен — доступ открыт (dev-режим), но в лог пишется ERROR и
  админу (`ADMIN_IDS`) уходит однократное предупреждение.
* **Приветствие новичков (v1.5.6).** Когда человек подписывается на канал
  или вступает в отслеживаемую группу, бот отправляет ему одиночное
  приветствие в ЛС с кнопкой «Начать» (события `chat_member` по всем
  отслеживаемым чатам + `new_chat_members` с немедленной доставкой +
  детекция по первому сообщению + фоновый скан участников). Перед
  отправкой членство верифицируется через API; отметка `welcomed_at`
  гарантирует ровно одно приветствие, а неотправленные (закрытые ЛС)
  догоняются повторными сигналами и сканом. Для приёма `chat_member`
  бот должен быть админом чата, а апдейт — включён в `allowed_updates`
  (в `main.py` это сделано).

## 🧭 Навигация

Единый стандарт для всех экранов бота:

* контентные кнопки — **по 2 в ряд**, до **3 рядов** на страницу;
* ниже — строка навигации: `◀️ · «Название страницы 📖 i/n» · ▶️` (зациклено);
* внизу ровно **одна** кнопка выхода — `🏠 Меню`; никаких дублей «Назад».

Главное меню состоит из двух страниц:

| Страница | Кнопки |
|---|---|
| 🎮 Игра | 🐾 Питомец · 🛒 Магазин · 🧢 Мерч канала (при `MERCH_ENABLED`) |
| 👤 Профиль | 📊 Статистика · 🏆 Награды · 🏅 Топы · 🖼 Карточка · ⚙️ Уведомления |

Отдельно в меню присутствует реферальная ссылка «Пригласить друга» (url-кнопка
на канал с параметром `?start=invite_<tg_id>`).

## 🐾 Питомец (тамагочи)

У каждого пользователя свой питомец со шкалами **сытости, настроения, энергии и
гигиены**, уровнем, силой/ловкостью/интеллектом и монетами. Хаб питомца — три
страницы навигации:

* **🧴 Уход:** 🍎 Покормить, 🛁 Помыть, 💤 Спать, 🏋️ Тренировки (+ история ухаживаний);
* **🎒 Вещи:** 🎒 Инвентарь, 🛒 Магазин, 🎨 Стиль;
* **🎮 Досуг:** 🎾 Мини-игры, 🚶 Прогулка, 🐾 Друзья, 🏟 Арена.

Особенности:

* **Виды питомцев:** 🐱 Котёнок (бесплатный стартовый), 🐶 Щенок (150),
  🦊 Лисёнок (250), 🦉 Совёнок (350), 🐉 Дракончик (800, редкий универсал).
  Каждый вид имеет свои множители деградации, стартовые характеристики,
  любимые занятия и бонусы (XP/монеты/восстановление во сне).
* **Характер и предпочтения:** действия, которые питомец любит, дают больше
  счастья; нелюбимые (например, мытьё для кота) — меньше или с капризом.
* **Деградация и критическое состояние:** шкалы медленно падают со временем;
  когда всё совсем плохо, питомец уходит в «критическое» состояние — хаб
  предлагает 💖 Реанимацию за монеты (новичкам — бесплатно один раз),
  🥚 Усыновить нового или 📜 Посмотреть историю.
* **Кастомизация:** цвета (🌟 Золотой, 🌑 Теневой, 🍬 Карамельный, 🌈 Полярное
  сияние) и аксессуары (🎩 Цилиндр, 🎀 Бантик, 🕶️ Очки, 👑 Корона, 🧣 Шарф) —
  покупаются за монеты, применяются мгновенно.
* **Погода/сезоны:** сезонная модификация скорости деградации (`WEATHER_ENABLED`).

## 🛒 Магазин и инвентарь

Покупка товаров за монеты, заработанные активностью в чате и мини-играх:

* 🍎 Еда: Хлеб, Яблоко, Стейк, Тортик — восстанавливают сытость (у тортика —
  счастье ценой гигиены);
* ⚽ Игрушки: Мячик, Лазерная указка — поднимают настроение, иногда дают
  тренировку ловкости;
* 💊 Медицина: Лекарство, Витамины — лечат и бодрят.

Все купленные предметы попадают в **инвентарь**; там их можно применить к
питомцу одним нажатием. Цены и эффекты задаются сидом `ITEMS_SEED` (легко
расширять).

## 🧢 Мерч канала

Отдельный раздел магазина мерча (не связан с питомцем), включается флагом
`MERCH_ENABLED`:

* витрина категорий: футболки, худи, аксессуары;
* позиции задаются конфигом `MERCH_ITEMS` («Категория|Название|Цена₽|Описание|Размеры;…»);
* внешняя ссылка на магазин — кнопка «🌐 Открыть» (`MERCH_URL`).

## 🎮 Мини-игры

Играются в ЛС, тратят энергию питомца и приносят монеты/XP:

* ✊✋✌️ **Камень-ножницы-бумага** против питомца;
* ⚡ **Реакция** — нажать кнопку как можно быстрее (гонка на время);
* ❓ **Угадайка** — угадать число/символ с подсказками (`guess_hint_keyboard`).

## 🏟 Арена и социальные механики

* **Арена (duels):** еженедельная лига питомцев. Питомцы дерутся по статам
  (сила/ловкость/интеллект + уровень), побеждённый получает кулдаун, победитель
  — славу и призы. В конце недели подводятся итоги и выдаётся награда
  (`/award`, таблица PetDuel + недельные снапшоты).
* **Друзья:** питомцы могут «подружиться» (PetFriend) — влияет на прогулки и
  взаимодействия.
* **Прогулки:** случайные события, находки монет, знакомства с чужими питомцами.

## 🏅 Достижения, топы, статистика

* **Достижения:** десятки ачивок по категориям (💬 Активность, 🔥 Стрики, 😀 Реакции,
  🐾 Питомец, 🏟 Арена…), с редкостями (обычные/редкие/эпические/легендарные),
  наградами в монетах/XP и уведомлением об открытии. Экран «🏆 Награды» —
  список открытых/закрытых с прогрессом, пагинация по 8 штук.
* **Статистика:** личные метрики (сообщения, реакции получены/поставлены,
  стрик, XP, уровень, монеты, питомец) + разбивка по дням.
* **Топы:** номинации 👑 Общий, 💬 Болтуны, 💖 Реакции, 🎭 Эмоциональные,
  💚 Добряки, 🔥 Серии, 🐾 Питомцы, ⭐ Уровни; периоды 📅 День / 🗓 Неделя /
  ♾ Всё время; своя строка подсвечивается.
* **Карточка профиля:** PNG-карточка (уровень, статы, питомец, достижения),
  рендерится на лету и кешируется по содержимому.

## 🔔 Уведомления и вовлечение

Все уведомления приходят **только в ЛС** и управляются тумблерами в разделе
«⚙️ Уведомления»:

* 🐾 «Питомец скучает» (не чаще раза в N часов);
* 🔥 «Стрик под угрозой» (за несколько часов до полуночи);
* 🏆 Поздравление с новым достижением;
* 🌅 Ежедневный отчёт (XP/монеты/место в топах за день).

## 🤝 Рефералка

Кнопка «Пригласить друга» ведёт на канал со ссылкой `t.me/<channel>?start=invite_<tg_id>`.
Приглашённый становится рефералом, пригласивший получает `INVITE_REWARD_COINS`
монет (награда выдаётся однократно на факт присоединения).

## 🧰 Команды (только в ЛС)

| Команда | Действие |
|---|---|
| `/start` | Главное меню (для неподписанных — заглушка с ссылкой на канал) |
| `/help` | Краткая справка по возможностям |
| `/pet` | Хаб питомца |
| `/stats` | Статистика |
| `/top` | Топы |
| `/ach` | Достижения |
| `/card` | PNG-карточка профиля |
| `/settings` | Настройки уведомлений |
| `/arena` | Арена |
| `/award` | Итоги прошлой недели арены и выданные призы |

Команды, вызванные в группе/канале, игнорируются (см. «Модель доступа»).

## ⚙️ Быстрый старт (Windows Server)

```bat
:: 1. Установить Python 3.12 x64 (галочка "Add to PATH") и MySQL 8 Community
:: 2. Распаковать проект, например в C:\tamabot\
cd C:\tamabot

install.bat    :: 3. Один раз: venv + зависимости + создание .env (откроется блокнот)
               ::    заполнить BOT_TOKEN, DATABASE_URL, TRACKED_CHAT_IDS, ADMIN_IDS,
               ::    CHANNEL_USERNAME (гейт доступа только для подписчиков канала)
run.bat        :: 4. Запуск бота с живыми цветными логами в реальном времени
console.bat    :: 5. (альтернатива) TamaConsole — полноэкранное управление:
               ::    вкладки Логи / Дашборд / БД / Настройки / Пользователи,
               ::    кнопки Пуск / Стоп / Рестарт, редактирование .env из UI
```

⚠️ **Важно:** `install.bat`, `run.bat`, `console.bat` сохранены в кодировке
**cp1251 (ANSI Russian) с CRLF** + переключение `chcp 1251` — обязательное требование
`cmd.exe`. При редактировании сохраняйте именно в cp1251/«Кириллица Windows»
(Notepad++ → Кодировки → Кириллица → Windows-1251), иначе cmd перестанет понимать скрипты.

### Требования к правам бота

* **Канал:** бот — администратор с правом *Manage users* (для событий `chat_member`
  и проверки подписки `getChatMember`). Бот **не публикует** ничего в канале.
* **Группа обсуждения:** бот — участник/админ для чтения сообщений и реакций
  (трекер активности). Ответы в группу не отправляются.

## 🧪 Тесты

```bash
cd bot
python -m pytest tests/ -q
```

Единый тестовый набор `bot/tests/test_all.py` покрывает навигацию (2×3, ◀️ 📖 i/n ▶️,
один выход 🏠), гейт доступа (молчание в группах, блокировка без подписки, fail-open,
кэш), приветствия (идемпотентность, ровно одно DM), БД-репозитории и конфигурацию.

## 🗂 Структура проекта

```
bot/
  app/
    main.py            # точка входа: polling/webhook, регистрация middleware/роутеров

  console/             # TamaConsole (Textual): логи/дашборд/БД/настройки/юзеры
  tests/               # pytest-сьют (единый test_all.py)
README.md              # этот файл — быстрый старт
bot/README.md          # полная документация
```
