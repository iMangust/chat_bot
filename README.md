Многофункциональный развлекательный Telegram-бот с системой достижений, геймификацией и полноценным виртуальным питомцем (тамагочи). Работает в связке **«Канал + привязанная группа обсуждения»**, всё взаимодействие — через **личные сообщения** с интерактивными кнопками.

---

## ✨ Возможности

### 👋 Приветствие новичков
- Отслеживает событие `new_chat_members` в привязанной группе
- Отправляет приветствие **в личные сообщения** с онбордингом
- Если ЛС закрыты — упоминает в группе с просьбой написать боту
- Онбординг: выбор имени питомца, краткий туториал

### 📊 Трекер активности
- Количество сообщений (день / неделя / всё время)
- Поставленные и полученные реакции
- Длина сообщений, медиа, стикеры, голосовые
- Серии дней подряд (streak)
- Reply-взаимодействия и упоминания
- Антифрод: кулдауны, минимальная длина, фильтр флуда

### 🏆 Система достижений
- **Категории**: активность, стрики, реакции, тамагочи, социальные, секретные
- Прогресс-бары и уведомления о разблокировке
- Скрытые ачивки с особыми условиями
- Награды: XP и монеты

### 🐣 Тамагочи (полноценный, не заглушка)
- **Статы**: голод, счастье, энергия, гигиена, здоровье, настроение
- **Оффлайн-прогресс**: статы деградируют со временем, питомец может заболеть
- **Действия**: кормление, игры, сон, мытьё, лечение, тренировки
- **Мини-игры**: угадай число, камень-ножницы-бумага, реакция
- **Эволюция**: яйцо → детёныш → подросток → взрослый → легендарный
- **Прогулки**: рандомные ивенты (нашёл монету, подружился, простудился)
- **Магазин**: еда, игрушки, скины, аксессуары
- **Экономика**: внутренняя валюта, покупки, награды
- **Дружба питомцев** между пользователями
- **Погода и сезоны**: влияют на эффективность действий
- **Лидерборды питомцев**: недельные соревнования

### 📈 Статистика и лидерборды
- Топ-10 болтунов (день / неделя / всё время)
- Топ по реакциям, стрикам, уровню питомца
- Личная статистика с графиками
- Карточка профиля в виде картинки (Pillow)

### 🎯 Уровни и XP
- XP за сообщения, реакции, действия с питомцем
- Формула роста: `xp_needed = base * level^1.5`
- Автоматические роли в группе за уровни

### 🔔 Уведомления и вовлечение
- Пуши в ЛС: «Питомец скучает!», «Стрик под угрозой!»
- Ежедневный отчёт активности
- Утренние и вечерние напоминания
- Праздничные события (Новый год, Хэллоуин и т.д.)
